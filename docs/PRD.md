# 찬양 반주 생성 앱 MVP PRD

## 🎯 핵심 정보

**목적**: 찬양 인도자가 코드 악보 사진을 업로드하면 자동으로 다악기 반주 트랙을 생성하고, 예배 중 실시간으로 구간을 전환해도 끊김 없이 재생되게 한다.
**사용자**: 매주 예배 반주를 직접 준비해야 하는 교회 찬양 인도자 및 워십팀.

## 📖 용어

| 데이터 모델·코드상 명칭 | 실제 UI 표시 문구 | 비고 |
|---|---|---|
| `Setlist` (문서상 "세트리스트") | **찬양콘티** | "세트리스트"는 공연·콘서트 업계에서 온 표현이라 교회 찬양팀에는 낯설다. 실제 사용자(찬양 인도자·워십팀)에게 익숙한 "찬양콘티"를 모든 사용자 노출 문구(화면 라벨, 버튼, 안내 문구 등)에 사용한다. 데이터 모델·API·코드상 엔티티명(`Setlist`, `SetlistItem`, `setlistRepository` 등)과 URL 경로(`/setlists/...`)는 영어 기술 용어로 그대로 유지하며, 이 문서 본문에서도 데이터 모델을 설명할 때는 계속 "세트리스트"라는 표현을 병용한다. |

## 🚶 사용자 여정

```
1. 로그인 페이지
   ↓ 로그인 성공

2. 홈
   ↓ "악보 업로드" 클릭

3. 악보 업로드 페이지
   ↓ 이미지 4~5장 업로드 및 제출

4. 추출 진행 페이지
   ↓ 자동 추출 완료

5. 교정 페이지
   ↓ 코드/가사/섹션 확인 및 수정 후 저장

6. 편곡 설정 페이지
   ↓ 장르 프리셋 선택 및 반주 생성

   [저장만 하고 나중에 재생] → 홈으로 이동
   [바로 세트리스트에 추가] → 세트리스트 구성 페이지
   ↓

7. 세트리스트 구성 페이지
   ↓ 곡 순서 배치 후 "예배 시작"

8. 반주 사전 로딩 (F015)
   ↓ 로딩 완료 시 자동 진행

9. 실시간 재생 페이지
   ↓ 재생 중 선택

   [다음 섹션] → 같은 곡 다음 구간 재생
   [구간 반복] → 현재 구간 반복 재생
   [특정 섹션 점프] → 선택한 섹션으로 즉시 이동
   [다음 곡] → 세트리스트의 다음 곡으로 전환
   ↓

10. [예배 종료] → 홈으로 복귀
```

- 로그인하지 않은 사용자는 홈 진입 시 로그인 페이지로 자동 리디렉션된다.
- 교정 페이지에서 저장하지 않고 이탈하면 추출 결과는 임시 저장 상태로 남아 다음 접속 시 이어서 교정할 수 있다.

## ⚡ 기능 명세

### 1. MVP 핵심 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|-------------|------------|
| **[F001]** | 악보 이미지 업로드 | 곡 1개당 4~5장의 리드시트 이미지를 업로드 | 모든 기능의 입력 데이터 확보 | 악보 업로드 페이지 |
| **[F002]** | 가사/코드/조표 추출 | 비전 LLM으로 가사, 코드, 조표를 JSON으로 추출(텍스트 판독 영역) | 수작업 입력 없이 반주 생성의 기초 데이터 확보 | 추출 진행 페이지, 교정 페이지 |
| **[F013]** | 마디/박자 구조 추출 | 비전 LLM으로 마디 경계, 줄별 박자 수, 반복(도돌이표) 위치를 추출(정확도는 실사용 검증 필요) | 반주 타이밍 계산의 기초 데이터 확보 | 추출 진행 페이지, 교정 페이지 |
| **[F003]** | 코드 문법 자동 검증 | 추출된 코드 문자열을 코드 문법 규칙으로 재검증, 오류 항목 표시 | 잘못된 코드로 반주가 생성되는 것을 방지 | 교정 페이지 |
| **[F004]** | 섹션 자동 추론 | 반복 패턴과 도돌이표 위치로 절/후렴/브릿지 등을 자동 라벨링 | 인도자가 매번 처음부터 구조를 나누지 않아도 됨 | 교정 페이지 |
| **[F005]** | 수동 교정 | 원본 이미지와 나란히 코드 위치, 가사, 섹션 라벨, 키/템포/박자를 직접 수정 | 자동 추출 오류에 대한 최종 방어선 | 교정 페이지 |
| **[F006]** | 다악기 편곡 자동 생성 | 장르 프리셋(피아노/기타/베이스/드럼) 기반으로 MIDI 반주 트랙 생성 | 인도자가 직접 편곡하지 않아도 즉시 반주 확보 | 편곡 설정 페이지 |
| **[F007]** | 곡 재생 제어 | 생성된 반주 트랙의 재생/일시정지/구간 탐색 | 반주 생성 결과를 실제로 들어보고 확인 | 실시간 재생 페이지 |
| **[F008]** | 실시간 구간 전환 | 재생 중 다음 섹션/현재 구간 반복/특정 섹션 점프를 끊김 없이 수행 | 예배 중 즉흥적인 진행 변경에 대응하는 핵심 가치 | 실시간 재생 페이지 |
| **[F009]** | 다음 곡 전환 | 세트리스트 상 다음 곡으로 무음 간격 없이 전환(곡마다 조·템포가 달라도 전환 자체는 매끄럽게 이어짐) | 여러 곡을 하나의 흐름으로 진행해야 하는 예배 특성 | 실시간 재생 페이지 |
| **[F011]** | 세트리스트 구성 | 그날 부를 곡들을 순서대로 배치 | 실시간 재생과 다음 곡 전환의 전제 조건 | 세트리스트 구성 페이지, 홈 |

### 2. MVP 필수 지원 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|-------------|------------|
| **[F010]** | 기본 인증 | 회원가입/로그인/로그아웃만 | 서비스 이용을 위한 최소 인증 | 로그인 페이지, 회원가입 페이지 |
| **[F012]** | 곡/세트리스트 목록 조회 | 저장된 곡과 세트리스트를 홈에서 확인 및 선택 | 업로드·편곡·재생 흐름의 진입점 | 홈 |
| **[F014]** | 재생 안정성 확보 | 화면 꺼짐 방지, 오디오 자동 재개, 재생 시작 전 활성화 동작 | 예배 중 재생이 끊기면 서비스 신뢰성이 무너짐 | 실시간 재생 페이지 |
| **[F015]** | 반주 사전 로딩 | 재생 시작 전 필요한 사운드·트랙 데이터를 미리 불러오고 로딩 완료 표시 | 예배 시작 시점에 반주가 즉시 재생 가능해야 함 | 실시간 재생 페이지 |

### 3. MVP 이후 기능 (제외)

- 멀티테넌시/조직(교회) 관리 및 멤버 권한 구분
- 결제 및 구독 관리
- 프로필 상세 관리
- 설정(테마, 언어, 알림)
- 오프라인 캐싱 및 PWA 지원
- 네이티브 모바일 앱
- 세트리스트 공유 및 협업

| **역할** | 예배 중 실제로 반주를 재생하고 실시간으로 진행을 제어하는 핵심 화면 |
| **진입 경로** | 세트리스트 구성 페이지에서 "예배 시작" 클릭 → 반주 사전 로딩 완료 후 자동 표시 |
| **사용자 행동** | 반주를 재생하며 필요 시 다음 섹션/구간 반복/특정 섹션 점프/다음 곡 중 선택 |

## 🗄️ 데이터 모델

### User (사용자)
| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | 사용자 식별자(Clerk user_id 참조) | string |
| display_name | 앱 내 표시 이름 | string |
| created_at | 최초 접속 일시 | datetime |

### Song (곡)
| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | 고유 식별자 | UUID |
| title | 곡 제목 | string |
| key | 조표 | string |
| tempo | 템포(BPM) | integer |
| time_signature | 박자표 | string |
| status | 처리 상태(임시저장/추출완료/교정완료) | string |
| created_by | 등록한 사용자 | → User.id |

### Section (섹션: 절/후렴/브릿지 등)
| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | 고유 식별자 | UUID |
| song_id | 소속 곡 | → Song.id |
| type | 섹션 유형(절/후렴/브릿지 등) | string |
| order_index | 곡 내 기본 순서 | integer |
| start_beat | 곡 시작 기준 절대 박자 위치 | float |
| length_beats | 섹션 길이(박자 수) | float |
| repeat_target_section_id | 도돌이표 등 반복 시 이동할 섹션(있는 경우) | → Section.id |

### Line (가사 줄)
| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | 고유 식별자 | UUID |
| section_id | 소속 섹션 | → Section.id |
| lyrics | 가사 텍스트 | string |
| order_index | 섹션 내 줄 순서 | integer |
| start_beat | 섹션 시작 기준 박자 위치 | float |

### ChordEvent (코드 이벤트)
| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | 고유 식별자 | UUID |
| line_id | 소속 가사 줄 | → Line.id |
| chord | 코드 기호 | string |
| char_offset | 가사 내 문자 위치 | integer |
| beat_offset | 소속 줄(Line) 시작 기준 박자 위치 | float |
| needs_review | 코드 문법 검증 실패 등 교정 필요 여부 | boolean |

### Arrangement (편곡)
| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | 고유 식별자 | UUID |
| song_id | 대상 곡 | → Song.id |
| genre_preset | 선택한 장르 프리셋 | string |
| created_at | 생성 일시 | datetime |

### InstrumentTrack (악기별 트랙)
| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | 고유 식별자 | UUID |
| arrangement_id | 소속 편곡 | → Arrangement.id |
| instrument | 악기 종류(피아노/기타/베이스/드럼) | string |
| notes | 노트 이벤트 목록(박자 위치·음높이·길이·세기, JSON) | json |

### Setlist (세트리스트)
| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | 고유 식별자 | UUID |
| name | 세트리스트 이름 | string |
| owner_id | 소유 사용자 | → User.id |
| created_at | 생성 일시 | datetime |

### SetlistItem (세트리스트 항목)
| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | 고유 식별자 | UUID |
| setlist_id | 소속 세트리스트 | → Setlist.id |
| song_id | 대상 곡 | → Song.id |
| arrangement_id | 재생할 편곡 지정 | → Arrangement.id |
| order_index | 세트리스트 내 순서 | integer |

## 🛠️ 기술 스택 (최신 버전)

### 🎨 프론트엔드 프레임워크

- **Next.js 16** (App Router) - React 풀스택 프레임워크
- **TypeScript 5.6+** - 타입 안전성 보장
- **React 19** - UI 라이브러리 (최신 동시성 기능)

### 🎨 스타일링 & UI

- **TailwindCSS v4** (설정파일 없는 새로운 엔진) - 유틸리티 CSS 프레임워크
- **shadcn/ui** - 고품질 React 컴포넌트 라이브러리
- **Lucide React** - 아이콘 라이브러리

### 📝 폼 & 검증

- **React Hook Form 7.x** - 폼 상태 관리
- **Zod** - 스키마 검증 라이브러리
